# The Rhythms of Renewal

A browser-based presentation by Pastor Andy Addis, adapted to the Send Network Replant & Renewal presentation template.

## Presenting

Open `index.html` in a modern browser. Navigate with:

- Right arrow, down arrow, Page Down, spacebar, or Enter to advance
- Left arrow, up arrow, Page Up, or Backspace to go back
- Swipe gestures on touch devices
- `F` to enter full-screen mode

Slides 3 and 5 reveal list items individually, alternating between the left and right columns.
